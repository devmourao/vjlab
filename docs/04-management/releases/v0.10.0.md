## 2. Executive Summary

Playlist release: session media queue and scene setlist with favorites, built on the track and library models with zero backend.

## 3. New Features

* Local media queue — add multiple files, reorder up/down, remove with URL revoke, play by click with queue position.
* Scene setlist and favorites — persisted order, favorite toggles surfacing as numeric shortcuts 1–6 with fallback to setlist.
* Queue-aware navigation — N/P, autopilot tour and control channel follow setlist order.

## 4. Improvements

* Track model extended with optional URLs; audio engine loads queued URLs without touching file ownership.
* Keyboard digits resolve favorites first, then setlist position.

## 5. Fixes

* No defect fixes in this release; feature delivery only.

## 6. Known Limitations

* Media queue is session-only; files stay in memory until reload (hint shown in UI).
* Object URLs are revoked on remove; cleared site data drops custom scenes, order and favorites.
