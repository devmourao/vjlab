## 2. Executive Summary

Builder release: visual preset assembly from the native base catalog with isolated live preview and schema-driven knobs, on top of the scene library foundation.

## 3. New Features

* Preset builder modal — base browser, isolated mini-stage preview and generic knobs saving through custom scenes.
* Shared instance renderer between live stage and preview with read-only audio.
* Shared schema-driven param fields between editor and builder.
* Pure draft validation with unit coverage.

## 4. Improvements

* Scene editor refactored onto the shared knob source; single knob behavior everywhere.

## 5. Fixes

* Fixed a wrong module import for the base id type in builder components.

## 6. Known Limitations

* Preview uses default camera framing; saved scenes play under the live camera rig.
* Session image uploads are not embedded in exports; re-attach after import.
