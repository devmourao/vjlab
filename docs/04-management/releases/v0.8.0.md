## 2. Executive Summary

Clarity release: one panel surface instead of duplicated sides, a dedicated player with a future-ready model, and explicit hide vs pop-out commands that never cost fullscreen.

## 3. New Features

* Unified side panel with Track, Scenes, FX and Guide tabs for docked and detached modes.
* Dedicated desktop player strip with track identity and transport.
* Scene library model with setlist order and favorites, reorder-ready for future queues.
* Dedicated pop-out control (button plus D shortcut) owning the second screen.

## 4. Improvements

* Right desk surface retired; shared scene list and guide entry across panel and sheet.
* Hide UI toggles visibility only and never opens popups or exits fullscreen.
* Shortcut map, guide and tour copy aligned with the new control meanings.

## 5. Fixes

* No defect fixes in this release; hardening only.

## 6. Known Limitations

* Local audio upload stays on the main deck; the popup mirrors status and play/pause only.
* Second screen requires same-origin windows and a user gesture; blocked popups fall back to the in-page panel.
* Setlist management UI is deferred; the model is forward-compatible only.
* Auto-pilot uses fixed 5s interval; not yet audio-synced.
* Heavy effect stacks may hitch on weak GPUs (lite mode mitigates).
