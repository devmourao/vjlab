## 2. Executive Summary

Polish release: one responsive standard across the shell and a focused deck entry led by a single reusable track card.

## 3. New Features

* Responsive shell standard — single breakpoint source with aligned queries across surfaces.
* Deck entry sequence — focus mode without side-desk pollution, staged reveal on first track, tour-aligned phases.
* Reusable track card with a queue-ready track model shared by the empty state, the audio panel and the control popup.

## 4. Improvements

* Safe-area coverage completed on the landing footer and the detached sheet.
* Player transport unified (load/change, play/pause) with queue position ready for a future playlist.

## 5. Fixes

* No defect fixes in this release; hardening only.

## 6. Known Limitations

* Local audio upload stays on the main deck; the popup mirrors status and play/pause only.
* Second screen requires same-origin windows and a user gesture; blocked popups fall back to the in-page panel.
* Auto-pilot uses fixed 5s interval; not yet audio-synced.
* Heavy effect stacks may hitch on weak GPUs (lite mode mitigates).
