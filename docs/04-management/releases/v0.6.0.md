## 2. Executive Summary

Web Experience release: public landing page, mobile-first control surface, guided onboarding, and second-screen direction with clean fullscreen output — all without breaking any existing shortcut.

## 3. New Features

* Landing route with presentation page and deck entry (`/` and `/deck` with static-host fallback).
* Mobile bottom sheet with Audio / Scenes / FX / Guide tabs and mini / half / expanded states; canvas stays mounted.
* First-run tour with skip and replay, help drawer derived from the shortcut map, and non-blocking empty-state upload CTA.
* Second-screen control popup with command/snapshot sync (no loops by construction) driving scenes, strobe, flags, effects, zoom and overlay.
* Dynamic viewport and safe-area handling so controls stay above mobile browser chrome and overlays.

## 4. Improvements

* Panel visibility evolution — always-visible toggle plus compact top bar with mode, fullscreen and guide entries.
* Detached fallback anchored as a readable side sheet instead of a broken centered box.
* Popup effect section regrouped with selectable slot grid, value bars, mix/zoom/strobe sliders and stacked overlay input.
* Responsive shell standard queued as a follow-up enhancement (backlog).

## 5. Fixes

* Detached panel rendering clipped controls with double scroll on desktop.
* Bottom controls hidden behind mobile browser navigation on small screens.

## 6. Known Limitations

* Local audio upload stays on the main deck; the popup mirrors track status and play/pause only.
* Second screen requires same-origin windows and a user gesture; blocked popups fall back to the in-page panel.
* Auto-pilot uses fixed 5s interval; not yet audio-synced.
* Heavy effect stacks may hitch on weak GPUs (lite mode mitigates).
