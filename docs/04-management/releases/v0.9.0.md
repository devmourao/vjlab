## 2. Executive Summary

Library release: single composition path with per-instance assets, a versioned pack format and user-owned scenes persisted as text — the playlist foundation.

## 3. New Features

* Instance-scoped composition — all presets resolve through `instances[]` with host-level parallax and zoom per instance.
* Native base capability registry with preset vs instance scope for validated editing.
* Per-instance image slots — mesh textures owned by the instance, not global state.
* Versioned scene and media pack format with validator (header, per-base rules, header and per-item reports, clamping, id namespacing).
* Scene CRUD v1 — create, edit and delete custom scenes from native bases with local persistence, plus text export/import with readable per-item reports (playlist born here).

## 4. Improvements

* Scene spec updated to single-path composition and registry reference.
* Preset honesty test: only honored params survive on any instance.
* Dynamic preset navigation (N/P, autopilot, control channel, SceneHost) now spans native and custom scenes.

## 5. Fixes

* Retired silently ignored legacy params (`count`, `shape`) that leaked into migrated presets.

## 6. Known Limitations

* Custom scenes live in `localStorage`; clearing site data removes them.
* Media packs validate `video` entries but playback is audio-only until the video plane lands.
* Pack `minAppVersion` is advisory; the validator reports incompatibility but does not auto-migrate.
